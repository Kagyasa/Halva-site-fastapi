Ветка на GitHub: update/v2.
1. Переключитесь на update/v2 в локальном проекте.
2. Скопируйте содержимое архива в корень проекта с заменой файлов.
3. Выполните git add ., git commit и git push origin update/v2.
Архив содержит текущие изменения интерфейса и тестов, а также документацию, отсутствующую в удалённой версии.
Файл .env и данные БД в архив не включены. Миграции не требуются.
Проверено: 50 тестов бэкенда на SQLite, npm test (каталог из 49 товаров), Ruff и Prettier.
Полный браузерный прогон Playwright локально недоступен: Chromium не запускается. Проверьте GitHub Actions после отправки.
Причина прошлого падения frontend: locator.fill strict mode violation, общий селектор находил 49 полей количества. Теперь поле выбирается по data-product-id.
